# Format: key = value   (spaces around '=' are trimmed)
#
# To contribute a new language:
#   1. Copy this file to romfs/lang/<your-code>.txt
#   2. Translate every value (right side of '='). Leave keys (left side) alone.
#   3. Register the locale in source/i18n.cpp (kAvailable list).
#   4. Open a Pull Request — partial translations are welcome.
